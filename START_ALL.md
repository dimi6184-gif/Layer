# 🚀 Bot & Dashboard starten

## Öffne 2 Terminals:

### Terminal 1 - Bot
```bash
cd apps/bot
npm run dev
```

### Terminal 2 - Dashboard
```bash
cd apps/web
npm run dev
```

## Dann öffne:
- Dashboard: http://localhost:3000
- Bot sollte in Discord online sein

## ✅ Fertig!

Jetzt kannst du:
1. Dashboard öffnen → Dein Server → Tickets
2. "Dropdown Menu Mode" aktivieren
3. Gründe hinzufügen/bearbeiten
4. Save Configuration
5. `/ticket panel` in Discord ausführen
6. Dropdown-Menü testen! 🎫
