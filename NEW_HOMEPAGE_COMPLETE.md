### 🎯 Key Elements:

**Buttons:**
```tsx
// Primary (Yellow)
className="px-8 py-4 bg-yellow-400 hover:bg-yellow-500 rounded-2xl hover:scale-105 hover:shadow-xl"

// Secondary (Gray)
className="px-8 py-4 bg-gray-100 hover:bg-gray-200 rounded-2xl"
```

**Feature Cards:**
```tsx
className="p-8 bg-white rounded-3xl hover:shadow-xl border border-gray-100"
```

**Badges:**
```tsx
className="px-4 py-2 bg-yellow-400/10 rounded-full"
```

**Gradient Text:**
```tsx
className="bg-gradient-to-r from-yellow-400 to-yellow-600 bg-clip-text text-transparent"
```
