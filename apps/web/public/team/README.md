# Team Images

Place your profile image here:

- **dimi.jpg** or **dimi.png** - Your profile picture (recommended size: 400x400px or higher, square format)

The image will be used on the About page as your profile picture next to your quote.

## Image Guidelines:
- Format: JPG or PNG
- Recommended size: 400x400px or larger
- Keep file size reasonable (< 500KB preferred)
- Square aspect ratio works best
