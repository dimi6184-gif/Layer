FAQ

You have questions.
We have answers.

How quickly can I get started?

Most servers are up in under 2 minutes. Add Layer, run /setup, and your server is protected instantly.

How does scam detection work?

Layer scans every image and message in real time. Threats deleted automatically before members see them.

Does Layer store my members' data

No. Zero emails, zero IPs, zero personal data. Everything stays inside Discord.

What is ban evasion tracking?

When a banned user rejoins with a new account, Layer detects and bans them automatically.

How does the AI ticket moderator work?

Layer scans your entire server first — every channel, category, and role — so it actually understands your community. When a ticket opens, it replies with full context. When staff joins, it steps back silently.

Can I configure everything without coding?

Yes. All from the dashboard. No code, no config files.
