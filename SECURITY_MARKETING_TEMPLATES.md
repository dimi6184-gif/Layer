## FAQ Additions

### Q: Is Layer affected by the Double Counter breach?
**A:** No. Layer was never connected to Double Counter. We built our own verification system from scratch with privacy as the foundation.

### Q: What data does Layer collect?
**A:** Only what Discord's API requires:
- Your Discord User ID (public)
- Your server membership (needed for roles)

We never collect emails, IPs, fingerprints, or location data.

### Q: How is Layer's verification different?
**A:** We use Discord's native OAuth. When you verify, Discord handles authentication — we never see passwords or emails. We just receive your User ID and assign the role.

### Q: Can Layer data be breached like Double Counter?
**A:** While no system is 100% breach-proof, Layer minimizes risk by not collecting sensitive data in the first place. We can't leak what we don't have.

### Q: Is Layer open source?
**A:** Yes. Our entire codebase is public on GitHub. You can audit it yourself and verify that we only collect what we say we do.
